# Referências

Uma linha por referência: o que o Lucas gostou nela e para que serve.

> **Falta colar as imagens aqui.** As referências foram mandadas no chat e
> não ficaram guardadas. Quando sobrarem, jogue os arquivos nesta pasta com
> nome limpo (`riso-mostrinho-azul.png`) e aponte na linha certa.

## Serviram para a direção escolhida (V2 Riso)

| Arquivo | O que o Lucas gostou | Serve para |
| --- | --- | --- |
| `[a colar]` | o mostrinho azul com escrita meio neon | a paleta inteira: azul, lima e rosa sobre fundo escuro |
| `[a colar]` | o gato sério com a escrita vermelha na cabeça | o mascote M2 — adulto, não fofo |
| `[a colar]` | o enquadramento de só a metade da cabeça aparecendo | o gato que espia por baixo da tela e reage com o olhar |

Em uma frase: contraste alto e cor chapada, **sem ser infantil**. Foi o que
separou a V2 das outras duas.
